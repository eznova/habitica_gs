# Google Tasks → Habitica Sync

Этот скрипт синхронизирует задачи из вашего Google Tasks в Habitica как задачи типа **"To-Do"**, включая:

* Название задачи
* Описание
* Дату и **время выполнения** (в формате MSK / UTC+3)
* Приоритет (по умолчанию 1.5)
* Пометку, чтобы не дублировать уже синхронизированные задачи

## 🔧 Требования

* Аккаунт в [Google](https://www.google.com/)
* Аккаунт в [Habitica](https://habitica.com/)
* Google Apps Script (например, через Google Таблицы: `Инструменты` → `Редактор скриптов`)
* Включённые API:

  * Google Tasks API
  * Google Calendar API (если используете напоминания из календаря)
  * UrlFetchApp (по умолчанию включён)

## 📦 Установка

1. Откройте Google Таблицу → `Инструменты` → `Редактор скриптов`
2. Вставьте скрипт `scheduleToDos` и объявите вверху глобальные переменные:

```javascript
const habId = "ВАШ_HABITICA_USER_ID";
const habToken = "ВАШ_HABITICA_API_TOKEN";
```

3. В Google Cloud Console включите **Google Tasks API** для этого проекта.
4. Разрешите скрипту доступ к задачам и интернету при первом запуске.

## 🚀 Использование

1. Запустите функцию `scheduleToDos` вручную или создайте триггер (например, ежедневно).
2. Скрипт получит список задач из всех списков Google Tasks.
3. Он создаст задачи в Habitica, избегая дублирования — каждая задача помечается в `notes` специальным тегом:

```
[SyncedFromGoogleTasks:id=1234567890]
```

4. Если у задачи в Google задана дата и время, в Habitica:

   * В поле `due` устанавливается дата.
   * Во имя задачи добавляется:
     `Название задачи (до 11:00 03.05.2025)`

## ⚙️ Форматирование времени

Все даты из Google Tasks приходят в UTC. Скрипт автоматически добавляет смещение +3 часа (MSK), чтобы правильно отобразить локальное время.

## ❗ Заметки

* Завершённые и удалённые задачи игнорируются.
* Приоритет у задач по умолчанию `1.5` (важные).
* Для отладки смотрите `Журнал` в редакторе скриптов (View → Logs).

## 📜 Пример задачи в Habitica

```
✅ Название: Купить молоко (до 19:00 02.05.2025)
🗒️ Notes:
  - [Описание из Google]
  - [SyncedFromGoogleTasks:id=abcdef123]
```

## 🛡️ Безопасность

Храните ваш Habitica API Token и User ID в переменных или зашифрованном хранилище, если используете скрипт в публичном доступе.
